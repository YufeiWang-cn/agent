# 示例 Agent／后端开发实习岗位

这是虚构 JD，仅用于功能验证，不是实际招聘信息。

## 工作内容

- 开发 Agent 应用的后端 API，接入模型服务和业务工具。
- 实现会话与任务状态持久化，处理工具失败、超时与取消。
- 参与检索与记忆能力开发，编写测试并根据结果定位问题。

## 要求

- 在校计算机相关专业学生，能够每周实习至少四天、连续三个月。
- 使用 Python 开发过项目，了解 HTTP API 和数据库基本操作。
- 能说明自己的项目职责、技术选择和问题解决过程。
- 有工具调用、检索或 Agent 应用经验加分。
- 不要求模型训练经历；没有实际使用过的技术不需要写入简历。
